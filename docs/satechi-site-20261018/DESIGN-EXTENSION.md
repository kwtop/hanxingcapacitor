## 依据与边界

视觉依据为 Satechi 实际页面研究：首页、产品目录、产品详情，以及先前完成的四视口首页测量和截图纠偏。暖白、悬浮白色导航、产品摄影、平面货架、不对称场景与胶囊按钮沿用参考站的设计关系。内页布局按 HAN XING 的选型、技术阅读和询盘任务转译，没有迁入零售价格、购物车、评分、客户背书或保修信息。

原有 31 个业务页面 URL、导航目标、技术数据、正文主标题、资料锚点、真实照片和询盘处理保持。首页可重组模块顺序。未发布的出口记录继续不进入导航。英语优先，不增加西语或阿语。

## 页面类型

| 类型 | 组成与图片组织 |
| --- | --- |
| 首页 | 摄影轮播 → 四系列入口 → 技术摄影横幅 → 产品货架 → 尺寸摄影横幅 → 指南货架 → 不对称应用拼版 → 图片询盘板 → 原始资料入口 → 页脚。保留摄影横幅与横向轨道，不统一改成网格。 |
| 产品总览 | 居中标题、简短筛选、四列白色产品货架。方形影棚图保留产品完整外形，卡片继续呈现系列参数。平板与手机两列。 |
| 产品详情 | 桌面图库在左、型号与关键参数在右；1440px 下列比 `1.15fr / .8fr`、间距 50px、右侧留 60px。首先展示重构影棚图，后续仍可浏览原图。技术表、样品、资料与询盘全部保留。手机先标题，再完整图库，再参数和询盘。 |
| 应用页 | 文字与较大的 3:2 设备场景图组成首屏；保留电路判断、系列比较、安装检查及询盘。图片完整呈现设备，不使用 `contain` 产生灰色补边。手机改为文字、行动、图片。 |
| 资源总览 / 技术目录 | 图片承担栏目识别；文章按已有技术主题分组。栏目数来自已发布内容，不为填版增加新闻或出口案例。 |
| 技术文章 | 居中标题、大幅 3:2 概念封面、桌面侧目录和 760px 阅读列。原始标签、端子照片及参数表仍放在正文对应位置。手机目录在上，表格局部滚动。 |
| About / OEM / 采购 | 不对称图文首屏；品牌产品、样品审批、包装概念各使用对应照片。身份记录、审批步骤与采购清单保留各自形式。 |
| 制造与质量 | 大幅原始生产静帧、原视频分组及文件检查；不把生成图用作制造实力证明。 |
| Contact | 桌面联系信息与产品摄影在左，白色表单在右；手机纵向阅读。保留真实联系方式、系列上下文和草稿流程。 |
| FAQ / 政策 / 原始图库 | 延用暖白、字体和边界规则；FAQ 保持折叠阅读，政策限制行宽，原始图库保持可核验图片。无需每页强塞摄影首屏。 |

## 响应式与图片

- 1440 / 1024 / 768 / 390px 分别验证。31 页覆盖桌面与手机，8 个代表页面追加两种中屏。
- 手机产品图库、设备首图保持主体完整；不通过放大裁掉端子、引线、安装脚来填充图片。
- 生成图按图位制作，输出 WebP；产品 1200px 方图，应用与文章 1536×1024px。显式宽高减少布局移动，首屏优先加载，其余懒加载。
- 本轮新增 20 张，原有首页研究素材继续使用 19 张。图片逐一记录原图来源、生成提示词、用途、尺寸及字节量，见 `IMAGE-RECORD.json`。
- 原始标志、印字、端子组数与外形作为生成约束。AI 展示图不能替代原始标签、型号图纸和证书核验；原始图库与真实生产影像继续公开可达。

## 工程隔离

`src/lib/visualPreview.ts` 只在 `import.meta.env.DEV` 且 `HANXING_VISUAL_PREVIEW=satechi` 时启用。布局、素材和页面增量均受该条件控制。预览具有 `noindex,nofollow,noarchive`，沿用真实 canonical 和结构化数据。原站与主题使用独立 Vite 缓存，可同时运行。

入口：`npm run dev:visual`，默认 `http://127.0.0.1:4340/`。无需改变 URL、数据源、构建栈或安装 UI 框架。主题样式不得回流到原站；新增业务事实必须仍从原数据与资料获得。
