## 素材与真实性

共7张内置 `image_gen.imagegen` 摄影重构，提供640 / 960 / 1536px WebP，共21个文件。生成图片仅用于编辑展示，替代文本与 `data-source-kind` 保留重构属性；原照片、四段原 MP4、技术数据和文档要求均保留。图片没有用于推导新的企业、证书、客户、生产能力或交付事实。

- 最终图片：`public/images/previews/oem-imagery-20261019/`
- 提示词：`IMAGEGEN.json`
- 输入、原生输出路径：`GENERATED.json`
- 尺寸、文件大小、来源：`MEDIA.json`
- 编码脚本：`prepare-media.mjs`，只缩放并编码生成结果，不修改源照片。

新视频封面使用响应式独立图片，按需加载；原视频继续 `preload=none`。播放、暂停和结束时封面退出；失败或取消时允许重新播放。包装原视频仍为540×960，以 contain 完整显示，静态封面没有灰色补边。播放竖片时的深色侧区用于保留完整画面。
