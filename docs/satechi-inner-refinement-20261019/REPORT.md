# Satechi 整站内页校准

完成日期：2026-10-19。本轮完成本地实施，未推送或部署，原站仍在4335。整站预览：[4340](http://127.0.0.1:4340/)，[前后对比](http://127.0.0.1:4342/satechi-inner-refinement-20261019/comparison.html)。

## 根因与范围

旧的 `4335/previews/satechi-home/` 是早期独立首页，普通导航链接仍指向4335原版内页。另一个整站预览虽然已有统一字体和图片，但分类、产品、文章仍保留较多原版网格与同质布局。本轮同时修正入口和内页结构，避免只解释链接问题而不处理视觉问题。

旧入口现为开发环境302跳转到4340，主导航、页脚、图库、文章与询盘都在同一预览中连续浏览。生产构建不启用预览主题。

## 三轮视觉修正

1. 分类、产品概览、Resources重点文章和文章导读先建立结构；实际截图发现旧卡片网格、规格碎格和图框空白仍在影响效果。
2. 应用图从约260px的小图恢复为整栏摄影；规格改成逐行数据；指南图框与图像高度一致，消除约330px多余空白；About左栏标题和入口形成紧凑组。
3. 补充真实产品用途短文、放大关联系列产品图；生成适合分类横幅的四系列摄影，并调整桌面高度和手机裁切。完成全站响应式和交互复核。

`before/`保留9个代表页面的调整前截图，`round-1/`、`round-2/`保留修正过程，`after/`为最终结果。产品长页采用真实滚动截图拼合，保留分段与scrollY；单独生成CSS像素规范化的首屏副本，原始截图保留。

## 图片与限制

本轮新增1张ImageGen宽幅构图，输出桌面与手机两份WebP，共约168KB；保持韩兴标志、系列外形和原有印字作为展示参考。其余沿用已有产品、应用、指南和有来源说明的工厂润色图。原始照片、生产录像和证据入口未替换，详见 `IMAGEGEN.md`。

Satechi的Urbane / Usual为商业字体，当前使用Manrope / Inter近似替代，字形与换行存在差异。产品分类横幅为430px而参考为约320px，这是为保留完整四系列产品与导航留出的适配；没有宣称像素级一致。B2B技术表格、模型文档和采购内容按真实任务保留，没有复制参考站的零售价格、评分或促销模块。询盘继续沿用原来的邮件与WhatsApp草稿流程。
