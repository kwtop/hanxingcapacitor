# 第2轮：图位、裁切与小屏细节

1440整页约7159px，与参考整页同高；这是模块几何校准的结果，不代表全部照片或文字像素相同。1024只剩约25px总高差，小屏保留参考未显示的内容，不能只用总高度衡量。

本轮确认并继续修正：

1. 手机横幅受后置宽屏aspect-ratio影响，700px高度反推出1718px宽度，造成布局视口扩张。已明确手机`width:100%; aspect-ratio:auto`，保留失败快照`390-invalid-overflow`，重新采集390，真实视口恢复390×844且无横向溢出。
2. 首屏需要中屏独立素材。已生成1024:840和768:800图，四个产品及关键引线端子均在画内；继续保留真实标识和标签。平板图的年份误写已通过局部ImageGen修正为源照片的2025。
3. 1024资料短条摘要导致换行及高度增加。缩短为具体名词/动作，仍保留四个原有入口。
4. 两张真实资料故事图的大小标题顺序与参考相反。恢复小标题在上、较大主标题在下；不改变原始照片。
5. 平板询盘区的文字段比参考多约26px。收紧表单、说明及直接联系的间距，保持678px方图与20px白板内距。
6. 手机应用标题原为一行，参考为两行。改为清楚说明业务范围的`Applications for single-phase motors`，限制标题行长；四类应用完整保留。
7. 桌面横轨只有四件内容，全部放得下时不显示无效箭头；有横向溢出时按起止位置禁用相应按钮。手机通过触摸、键盘直接浏览。
8. 截图时移动指针到无交互区域，避免把悬停白色按钮误判为默认样式。默认和hover另行验证。

采集脚本已将`instanceof HTMLImageElement`换为同义`tagName === 'IMG'`以适配浏览器只读环境，未更改真实页面数据。Python输出采用UTF-8，避免µ单位在Windows控制台编码时出错。
