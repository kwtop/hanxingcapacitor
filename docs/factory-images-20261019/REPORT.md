## 图片选择与处理

原素材已有设备操作、测试和包装人员，因此优先保留这些人物的工作状态、服装和主要设备关系，没有另造团队合影或使用西方模特。画面优化集中于曝光、白平衡、主体比例、金属质感及网页裁切。包装素材由竖图重构为横图，其横向背景包含推断补全，页面明确标为 AI-reconstructed scene。

## 页面实现

- FactoryMedia 为重构图统一提供描述和原片入口；页面附近使用简短 AI 处理说明，保留当前暖白、摄影和字体体系。
- VideoFigure 支持仅预览环境传入的重构封面，播放地址仍为原始四段视频；封面下有 Original frame 链接。
- 首页将偏暗的生产与样品封面替换为重构图；修正图片标题的白色对比度。
- OEM 三个入口的图片说明与标题保持对齐。About 只更新下方供货配图，已有产品首屏继续使用。
- 所有新增展示仅在 `npm run dev:visual` 下启用。旧首页、独立首页提案和正式构建路径保留。
